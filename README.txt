MS SPORTS PRO WEBSITE

This folder contains a complete responsive static website for MS Sports.

PAGES
1. index.html: Home page
2. products.html: Searchable and filterable product catalogue
3. customize.html: Interactive uniform concept designer with SVG download
4. team_orders.html: Club and league ordering workflow
5. samples.html: Sample request form
6. repeat_orders.html: Repeat order form
7. contact.html: Quote request builder
8. size_guide.html: Fitting process guide

FILES AND FEATURES
• Responsive desktop, tablet and phone layout
• Original MS Sports visual system in black, white and red
• Product illustrations stored as editable SVG files
• Product search and sport filters
• Quote list stored in the browser
• Interactive colour and jersey concept controls
• Downloadable SVG concept
• Downloadable team roster CSV template
• Quote, sample and repeat order message builders
• Instagram links
• Accessibility labels and reduced motion support
• No paid plugin, framework or build step

HOW TO OPEN
Open index.html directly in a browser.
For best testing run a local server inside this folder:
python -m http.server 8000
Then open http://localhost:8000

PUBLISHING
Netlify: drag this complete folder into Netlify Drop.
GitHub Pages: upload all files to a repository and enable Pages from the main branch.
Cloudflare Pages: connect the repository with no build command.

IMPORTANT LIMITS
This is a working front end website. It does not include a secure database, admin panel, payment processing, automatic email sending, live inventory or shipping calculation.
Forms prepare and copy enquiry text. Connect Formspree, Netlify Forms, a CRM or your own backend for real submissions.

REQUIRED CHANGES BEFORE PUBLIC LAUNCH
1. Replace the temporary original logo with the official MS Sports logo file.
2. Replace product illustrations with real MS Sports photography where available.
3. Add the official email, phone, business hours and legal business name.
4. Confirm every product, turnaround, delivery and pricing claim.
5. Add real privacy, return, warranty and shipping policies.
6. Connect forms to a real submission service.
7. Test every link and form on the published domain.

DESIGN RESEARCH
The site uses common custom teamwear commerce patterns such as sport based browsing, sample requests, design help, club orders and repeat orders. It does not copy another company's text, images or page design.
